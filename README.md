# Vector Search Engine

A semantic search engine built with Spring Boot, PostgreSQL, and pgvector.

This project explores the fundamentals of vector databases, embeddings, cosine similarity, and semantic retrieval by implementing a real-world vector search backend from scratch.

## Features

* Semantic similarity search
* Vector storage with pgvector
* Embedding-based document retrieval
* Spring Boot REST API
* PostgreSQL vector indexing
* Foundation for RAG architectures

## Tech Stack

* Java
* Spring Boot
* PostgreSQL
* pgvector
* Docker

## Learning Goals

This project focuses on understanding:

* How embeddings work
* Vector similarity search
* Cosine distance
* Retrieval systems
* Vector database architecture
* AI-powered backend systems
